# 需求陈述

## 目标
- 给谁用：被剪映字幕会员化（每月仅 1 次免费额度）挡住的桌面端视频/播客创作者；第一用户是项目作者本人（kindness-loop CH3 字幕流程）
- 核心价值：浏览器内本地 AI 字幕生成——免费、无上传（隐私）、无水印、导出 SRT 后可回剪映烧录；开源（MIT）建立个人品牌与案例资产

## 背景（已确认的市场判断）
- 剪映智能字幕已收入会员，免费额度每月 1 次 → 付费墙外溢需求真实存在
- 桌面端替代品真空（手机端有必剪/快影竞争，不进入）
- 定位：纯开源，零付费层；变现走下游（部署服务/接单/品牌）
- 形态：独立单页 Web 工具（不绑定 OpenCut），后续再考虑插件化/移动端

## 角色
- 创作者（唯一角色）：导入媒体 → 等待本地转写 → 校对编辑 → 导出 SRT

## 场景清单
- [ ] 主流程：导入视频/音频 → 浏览器抽音频 → 本地转写（进度可见）→ 字幕列表编辑（文本+时间轴微调）→ 导出 SRT
- [ ] 异常 1：浏览器不支持 WebGPU → 自动回退 WASM（更慢但可用）
- [ ] 异常 2：媒体无音轨/无人声 → 明确提示，不产出空 SRT
- [ ] 异常 3：转写中途失败/被中断 → 保留已完成片段，可重试
- [ ] 边界 1：超长视频（如 >30min）→ 预计耗时提示，分段处理不崩页
- [ ] 边界 2：断网状态 → 首次下载模型后全程离线可用（完全离线优先）
- [ ] 边界 3：大文件（如 >2GB）→ 浏览器内存约束下的上限提示

## 约束清单
- 环境：现代桌面浏览器（Chrome/Edge 优先），WebGPU 可选 + WASM 兜底
- 性能：RTF < 1（1 分钟音频转写 < 1 分钟，笔记本 4060 级）；中文准确率对标剪映 ≥ 90%（Phase 0 验收）
- 安全/隐私：音频永不上传；模型首次下载后浏览器缓存；无任何埋点/账号
- 交付：Phase 0（质量对决 PoC）先行，质量过关才进入 Phase 1（最小闭环）
- 输入：视频（mp4/mov 等）+ 纯音频（mp3/m4a/wav）✅已确认
- 导出：仅 SRT ✅已确认
- 托管：GitHub Pages + 国内可达 CDN 托管模型 ✅已确认
- 文档：README 仅中文 ✅已确认
- 许可：MIT，发布前凭据/隐私自查，内部素材不进公开仓库

## 优先级初步排序
- must: 导入→转写→编辑（文本+时间轴）→导出 SRT 全流程；中文识别质量达标；离线可用；进度反馈
- should: WebGPU/WASM 自动降级；无音轨检测；断点续转
- could: 字幕样式预览；批量处理；LLM 同音字纠错；多语言

## 未决细节（deferred → 决策点）
- 转写引擎最终选型（whisper vs FunASR，Phase 0 实测决胜）
- 字幕分行规则（每条字数上限，作者本人偏好 ≤10 字/条 jieba 切词，待确认是否作为默认）
- 超长视频具体阈值与分段策略
- 浏览器兼容矩阵最低版本线
- 前端技术栈（vanilla vs 框架）
