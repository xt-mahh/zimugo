特性.

为中文短视频创作者打磨的每一个细节。

🎯

中文转写

Whisper-small + 简体化，词边界智能分行（≤10 字/条可调），对标剪映主观准确率 ≥90%。

⚡

WebGPU 加速

显卡直跑量化模型，RTF 0.26–0.40（Intel iGPU 实测）；无 GPU 自动回落 WASM。

✂️

只留人话

Silero VAD 过滤静音与 BGM，音乐段复读块「(((((((((」整块丢弃，疑错条目高亮。

📝

内置编辑器

时间轴校验、逐条微调，一键导出 UTF-8 无 BOM 的 SRT，剪映 / Premiere 直用。

🖥️

桌面版

Wails v2 封装 Windows 单文件 exe，模型内嵌，双击即用，彻底离线。

🔍

可审计

SDDL 规格驱动开发——spec → 架构 → 测试 → 收敛判定全链路留痕，拒绝"感觉对了"。

工作原理.

五个处理环节全部运行在浏览器沙箱内（左一为输入）。

媒体文件→ 16kHz 解码→ Silero VAD 分段→ Whisper 推理→ 分行/去噪→ SRT 导出

一睹为快.

导入 → 转写 → 校对 → 导出，一气呵成。
